localhost: run open AI models on your own machine

A directory of 83 source-backed recipes for running 22 open model families locally. Each recipe gives the hardware it ran on, the memory it needs, measured speed with its source, and the exact commands. This page is an app; the text below is for readers that do not run JavaScript.

For AI agents

  • Use the CLI: pip install "git+https://github.com/shuenrui/localhost.git#subdirectory=cli", then localhost detect --json, localhost fit --json, localhost guide <recipe-id> --json, localhost check --json, localhost connect opencode --json.
  • Read the agent guide: llms.txt.
  • Per-recipe JSON is linked below. The whole dataset is also embedded in this page as <script id="data" type="application/json">.
  • Rules: copy only steps marked as commands ("kind": "cmd"), verbatim. Never invent commands. Say when the directory records nothing.
